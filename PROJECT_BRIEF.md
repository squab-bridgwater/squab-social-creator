# Squab Social Creator

## Purpose

Create a repeatable, zero-cost, human-approved social content workflow for
Squab Storage Bridgwater. The website is the control centre for both nine-post
batches and quick reactive one-off posts.

## Agreed workflow

1. Choose a professionally balanced campaign style, then set the seasonal
   brief and local focus. Topic, service and objective allocation is automatic,
   with optional refinements available when needed.
2. Copy the complete prompt generated by the website into ordinary ChatGPT.
3. Copy ChatGPT's single structured JSON response back into the website.
4. Import all content in one action.
5. Assign reusable Squab photographs, then review the artwork, captions,
   dates, times, CTAs, output formats and QA results.
6. Download one publishing pack containing the artwork, captions, schedule,
   reusable JSON and instructions.
7. Human-review and schedule the posts through Meta Business Suite.

## Deliberate boundaries

- The public static website does not call the OpenAI API.
- ChatGPT does not send content directly to the website.
- The website does not store an API key or Meta access token.
- Facebook and Instagram publishing remains a human-approved action in Meta
  Business Suite.
- These boundaries keep the workflow free and avoid exposing credentials in a
  public website.

## Brand rules

- Tone: warm, calm, empathetic, human and professional, with occasional gentle
  wit.
- Messaging: stress reduction, clear pricing, flexibility, peace of mind and
  local Bridgwater relevance.
- Sales style: transparent and informative. No aggressive selling, fake
  urgency or unsupported claims.
- Primary colours: `#f4941e`, `#e95822`, `#fabd75`, `#fddfb7`, `#000000`,
  `#313131`, `#d2d2d2` and `#ffffff`.
- Typography: Lato Black for main titles, Lato Bold for supporting headings
  and Lato Regular for body copy.
- Artwork size: 1080 x 1350 pixels.
- Imagery must visibly show the reason storage is useful. Avoid spotless,
  empty or already perfectly decluttered rooms.

## Required product features

- Guided five-step workflow
- Nine-post batch and one-off modes
- Editable service and objective weighting
- Fifteen campaign-style presets covering household, business, brand, local
  community and timely content
- Priority, optional and exclude topic controls with automatic allocation
- Optional advanced service and objective weighting
- Verified Squab facts library to prevent unsupported claims
- Complete ChatGPT prompt generation
- Structured JSON import and validation
- Six approved visual treatments
- Persistent reusable photograph library with automatic assignment
- Photograph replacement and artwork editing
- Caption, CTA, contact detail, date, time and publication-status editing
- Portrait, square and LinkedIn export choices
- Per-post and batch QA
- Saved campaign library with reopen, duplicate and status controls
- Complete ZIP publishing-pack export
- Contact-sheet export
- Clear Meta Business Suite handoff

## Definition of done

The workflow is complete when a user can start with one brief and finish with
a ZIP containing correctly named PNGs, matching captions, a posting schedule,
the reusable batch JSON and simple publishing instructions, without manually
re-entering each post.
